# APEX Pit Wall

Web-first Formula 1 race replay built with:

- React frontend in `project/`
- FastAPI backend in `src/web/`
- Shared FastF1 telemetry/cache pipeline in `src/`

This repository was originally forked from a desktop-oriented F1 replay project. The legacy PySide6/Arcade runtime has been removed so the repo now only keeps the code needed for the browser stack.

## Quick Start

```bash
pip install -r requirements.txt

cd project
npm install
npm run build
cd ..

python -m src.web.pit_wall_server
```

Open `http://localhost:8000/app/Pit%20Wall.html`.

## Project Layout

```text
.
├── assets/models/          # Source GLB models tracked in git
├── project/                # React app, static shell, build script
├── src/
│   ├── data/               # Arrow cache + telemetry storage helpers
│   ├── lib/                # Shared utility code
│   ├── web/                # FastAPI, playback loop, HTTP + WS routes
│   └── f1_data.py          # FastF1 session loading and dataset building
├── requirements.txt
└── test_*.py               # Python tests for the web/cache pipeline
```

## Notes

- `project/assets/` is generated by `npm run build` and is intentionally ignored.
- Cached race data lives under `cache/` and `computed_data/`; those directories are runtime data, not source.
- If you want to refresh a race cache, start the server with `APEX_FORCE_WEB_CACHE_REBUILD=1` or remove the relevant cached files.
